Versions and errata

This is an archive, so the rules that matter are the ones about not moving things.

1 · Nothing is overwritten

Every file keeps the address it was published at. A file at a given address does not change after it is published.

2 · A correction is a new version

Version 2 is published alongside version 1, at its own filename, on the same page. Version 1 stays retrievable and is marked superseded. A reader who cited version 1 can still fetch what they cited.

3 · Every change is dated and stated

The publication's page carries a dated line for each version saying what changed and why. "Minor edits" is not a description of a change.

4 · The hash is the check

The SHA-256 of each published file is printed beside it. If a file's hash ever differs from the one printed for its version, that is a fault rather than an edit, and it should be reported.

5 · What is not versioned

Repairs to a page's own HTML that do not change meaning — a broken link, a misspelling, a layout fix — are made in place. Anything touching a definition, a figure, a claim or a citation is a new version of the publication, not a repair to a page.

6 · Withdrawal

If something is wrong beyond correction, the page says so plainly at the top and the file stays where it is. Nothing published here is deleted.

Reporting an error

To matthew.kirby@driftlayer.org. A report that names the publication, the version and the passage is the one that gets fixed fastest.
